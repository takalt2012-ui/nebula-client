# Nebula Client — UI polish notes

A small round of cleanup for the launcher:

- Kept the original purple palette, but toned down the glow and glass effects.
- Made surfaces more solid and gave controls tighter, more deliberate corners.
- Reduced decorative shadows and accent-heavy hover styling.
- Kept the sunset artwork available for the Legacy appearance rather than removing it.
- Fixed the disabled Play button's palette reference.
- Made stroke-width literals explicit so newer Rust compilers don't need to guess their float type.

This is a UI refinement, not a change to Horizon's account or game-launch flow.
