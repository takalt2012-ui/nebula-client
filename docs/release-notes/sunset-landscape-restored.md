# Sunset landscape restored

[View the v0.2.3 release on GitHub](https://github.com/takalt2012-ui/nebula-client/releases/tag/v0.2.3)

This focused update brings the original immersive sunset scene back to Nebula Client.

- **Original landscape restored:** replaces the reduced background asset with the original, higher-resolution sunset image.
- **Cleaner scaling:** updates texture filtering so the landscape looks smoother when stretched across the launcher.

The aim is to restore the look of the immersive launcher—not redesign it.
